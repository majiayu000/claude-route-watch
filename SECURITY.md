# Security

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/majiayu000/claude-route-watch/security/advisories/new). Do not include credentials or sensitive connection captures in public issues. Only the latest default-branch code is supported during the initial preview.

The controller secret stays on the local machine. This observer is read-only, but is not a firewall or a guarantee against traffic escaping Mihomo.
